# 脚本与系统显式选项

仪表盘中间是**系统显式选项**（防泄漏、中国直连、严格路由）。执行顺序是：订阅 → 覆写脚本 → 系统选项 → 链式代理，冲突时以系统选项为准，开和关都会写进运行配置。DNS 相关选项只在订阅未配置时补默认值，不会替换你自己的 nameserver。

脚本页在仪表盘下方，只有启用覆写脚本时才出现。脚本页里是 `main()` 开关、编辑器和分流策略组开关。

内置脚本来自 [HiClash](https://github.com/dukangalex/HiClash) 的 `mihomoScript.js`，原作者 AIsouler。旧的空脚本会在导入或启动时换成这份。

`function main(config)` 的返回值覆写当前配置，但空的 `proxies` / `proxy-providers` 会保留原节点。服务正在运行时保存会重载。`main` 必须返回配置对象。没有 `main` 的脚本会跳过，不再把导入打成失败。

策略组里引用了不存在的节点时，导入会丢掉这些成员；一组被清空又没有订阅时，改为 `include-all` 并保留 `DIRECT`，避免「proxy group not found」。

## 分流开关只作用于开了脚本的配置

策略组属于配置本身。分流开关（`ruleOptionsEnable` 里声明的那些）**只有在当前配置启用了覆写脚本时才生效**——
判定依据是配置目录下的 `script.on`，和「要不要跑脚本」用的是同一个标记，不会出现两处判断不一致。

| 当前配置 | 分流开关 | 结果 |
|---|---|---|
| 启用脚本 | 开 | 生成/删除对应策略组，注入对应分流规则 |
| 启用脚本 | 关 | 从运行配置里去掉这个组，原本指向它的规则改到主组 |
| 未启用脚本 | 任意 | **完全不改动策略组与分流规则**，订阅原样生效 |

未启用脚本时仍会应用两类东西：

- 「网络防护」类开关（屏蔽国外 QUIC / WebRTC）：只增删 `REJECT` 规则，不新建或删除策略组；
- 系统显式选项里的防泄漏、中国直连、严格路由：同样只前置规则，不碰策略组。

这样在脚本页拨一个开关，不会把别的配置的代理页也一起改掉。代理页右上角的开关图标打开的是
**当前配置**的策略组开关页：顶部显示配置名和「本配置是否启用脚本」，未启用时开关置灰并说明原因，
可以直接在那里为这份配置打开脚本。

开关按作用域分成四组，服务分流用两列紧凑卡片（点击即切换），其余三组默认折叠：

| 分组 | 内容 |
|---|---|
| 服务分流 | YouTube / Google / AI / Netflix / Telegram 等按服务生成策略组 |
| 策略组结构 | 手动选择、自动选择、负载均衡、故障转移、极简模式、地区/倍率组 |
| 节点筛选 | 过滤低倍率 / 高倍率 / 非地区节点 |
| 网络防护 | 屏蔽国外 QUIC、WebRTC、强制 TUN、IPv4/IPv6 优先、链式代理 |

| 系统显式选项 | 默认 | 作用 |
|---|---|---|
| DNS 走代理 | 开 | 订阅没配 DNS 时才注入 1.1.1.1 / 8.8.8.8；已配置则只做补全，不覆盖 |
| 禁止系统 DNS | 开 | 去掉 `system://` |
| 关闭 IPv6 | 开 | 内核和 VPN 都不分配 IPv6 |
| 阻断 QUIC | 关 | 拒绝 UDP 443 |
| 嗅探防泄漏 | 开 | 嗅探并覆盖目标地址 |
| 中国大陆域名 / IP 直连、国内 DNS、局域网直连 | 开 | 对应规则和国内 DoH |
| 严格路由、禁止绕过 VPN | 关 | 打开后 VPN 接管全部地址并不允许绕过 |
| DNS 遵循规则 | 开 | DNS 出口跟分流走 |
