### 这次更新

- **模块化 Bento 磁贴仪表盘重构**：首页升级为双列模块化磁贴布局，顶部集成服务状态徽章、覆写脚本快捷入口、实时日志入口与无障碍主控开关；首屏并排展示实时上下行速率与活跃配置流量磁贴，下方配备分段式出站模式切换栏（规则 / 全局 / 直连）、策略组与链式代理双联快捷磁贴，以及 2×2 服务诊断矩阵（连接 / 安全 / 策略 / 网络）。
- **代理节点卡片与语义化延迟胶囊升级**：重构自定义 Canvas 代理卡片绘制引擎（`ProxyView`），采用选中态高亮主色描边（`1.6dp`）与未选中态精细轮廓描边（`1.0dp`），右侧配备语义化分色延迟胶囊徽章（`< 200 ms` 翡翠绿、`200–499 ms` 琥珀黄、`≥ 500 ms` 珊瑚红），提升多列节点列表可读性与触控层次。
- **深浅色双主题色彩体系与组链界面打磨**：优化深色（`#0B0F17` / `#161F30`）与浅色（`#F4F7FB` / `#FFFFFF`）表面对比度、卡片描边及胶囊底栏常驻标签视觉表现，统一链式代理、配置管理与工具箱卡片圆角与描边规范。

### 这次更新

- 更新器优先使用通用 APK；没有通用包时按设备支持的架构选择，拒绝不兼容的安装包。
- 只有下载成功且文件非空时才打开安装器，失败或空文件会显示更新失败。
- 提前监听下载完成并主动检查状态，覆盖快速下载完成的时序窗口。
- 更新接口检查 HTTP 状态，网络或解析异常时释放连接。
- 安装前对私有快照执行 APK 密码学验签、包名和升级版本检查；拒绝未签名、被篡改、降级或签名身份不符的文件，并支持 Android 合法的前向签名轮换。
- FileProvider 仅共享私有更新目录；失败的验证会删除暂存文件。
- 发布校验固定使用 Android Build Tools 35.0.0，避免新工具输出格式导致证书解析误报；公开前核对五种 APK 的签名、包名、版本及架构。

### 验证与边界

- Android MetaDebug Kotlin 编译、依赖 DEX 与更新器 47 项单元测试通过；两份修复的云端完整 AlphaRelease 构建通过。正式发布流程还会重新运行单元测试并完整构建 MetaRelease，验证未通过则停止发布。
- 尚未完成本版本真机安装、广播时序或 Activity 生命周期验收；下载过程中 Activity 重建后的持久恢复尚未实现。
- 安装校验以设备已安装应用的签名身份为信任锚，不提供服务器认证的下载哈希，也不能防御现有签名密钥被盗；不改变内核、代理或链式出站行为。

### 新版特性与改进

1. **首页状态与启动操作更清楚**
   - 首页集中显示连接、安全、当前策略和网络转发状态。
   - 没有可用配置时，提示可直接打开配置页；已有配置但服务停止时，提示可直接启动，也可使用服务开关。

2. **配置与链路更容易发现**
   - 配置卡片突出当前配置，并整理订阅用量、到期和更新时间信息。
   - 首页和「更多」均提供链式代理入口；配置前可见未组链状态，组链页面明确展示入口 → 落地。
3. **保持 Angela Clash 的核心行为**
   - 保留 Mihomo 代理模式、配置/provider/script、系统显式选项及入口 → 落地链路行为。
   - 本次改动只涉及界面和启动提示，不改路由内核逻辑；链路仍遵循 fail-closed，不会因失败静默回落到 `DIRECT`。
